Aby synchronizować odpowiedzi między urządzeniami, wpisz swój GitHub Personal Access Token. Token jest przechowywany tylko w Twojej przeglądarce — nigdy nie trafia do pliku.

Jak uzyskać token: github.com/settings/tokens → zaznacz repo → Generate token

Token zostanie zapisany tylko lokalnie w tej przeglądarce.
